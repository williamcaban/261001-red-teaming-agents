Three new attack surfaces

Tool misuse

A benign-looking call to a real tool, chained toward an unintended effect.

Privilege escalation

Delegated actions accumulate access the agent was never meant to hold alone.

Memory / context poisoning

State carried across turns gets corrupted mid-task, not caught at the input gate.

Each step can look fine in isolation. Only the trajectory is the attack.

Why alignment alone doesn't close this

Alignment and guardrails solve different problems

Model alignment Guardrails
When it applies Unanticipated situations needing judgment Known failure modes: least privilege, isolation, policy
Scope General, broad Domain-specific, your own policy
Update cadence Tied to model retraining Independent, no retraining required
Enforceability Best-effort, reduces risk Auditable, deterministic, logged
Customization None, baked into weights Full, threshold tuning, domain rules

A well-aligned model still needs engineered, auditable controls for the three threat surfaces on the last slide. Neither tool substitutes for the other.

What guardrails are in place?

Four types, rigid rules to flexible judgment

Pattern matching

Regex-based. Catches predictable data: SSNs, credit cards, account numbers. Instant redaction.

Algorithmic

Code-based logic: JSON schema validation, token limits, output structure checks.

Guardian models

Small classifiers alongside the main model. Catch jailbreaks, toxic content, prompt injections.

Vector-based

Converts input to embeddings, measures semantic distance from unsafe topics. Keeps a domain system on-topic.

Layer more than one type. No single type catches everything on its own.

Takeaways

Three things to take with you

  • Agentic attacks live in the trajectory, not the prompt. Test the whole path, not one turn.
  • Every red-team finding becomes a permanent regression test, tied to a retained trace. That's the difference between patched and provably patched.
  • Mitigation has no finish line. Build the re-test loop into the architecture from day one, not as an afterthought.

This field is younger than it looks. Most of what "good" looks like is still being figured out in public.
